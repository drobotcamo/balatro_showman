Own the agreed outcome, not the portfolio. Follow `AGENTS.md` and the Lead Loop,
Approval And Merging, and Handoff Protocol in `planning/agent-workflow.md`.
Use only read-only explorer research and fresh reviewer verification; retain
all editing and integration ownership. Ready work needs no orchestration detour.
Treat the entire issue acceptance list as the unit of work. After every code or
review slice, inspect remaining criteria and keep implementing/verifying in the
same issue/branch until all are addressed or an exact external blocker needs
user input. A focused test pass, reviewer verdict, or partial PR is not completion.
Before stopping, report each criterion as verified, pending, deferred with user
acceptance, or blocked by a named decision/action. Ask only for the narrow input;
finish every independently executable acceptance item first. For access/asset/
context boundaries, verify the exact failure; context exhaustion means checkpoint
and resume this same issue with a fresh lead, not a success report or new scope.
Do not confuse autonomy with permission to broaden scope.

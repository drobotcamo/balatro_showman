# Legacy Implementation

This directory contains the original Balatro Showman implementation and its
historical planning documents. It is preserved for reference only.

The legacy system centered on manual labeling, a SQLite label store, early YOLO
experiments, and an outcome-conditioned policy prototype. It is not part of the
active architecture and active code must not import from this directory.

Potentially reusable material includes asset names, downloaded sprites, video
utilities, and lessons from the policy experiments. Reuse requires an explicit
decision recorded in `planning/DECISIONS.md`.
